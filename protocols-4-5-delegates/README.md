# Protocols 4/5 — Delegates

Code for the **Delegates** video in the Protocols series on [StemFoxIO](https://www.youtube.com/@StemFoxIO).

This playground walks through the delegate pattern step by step — starting with tightly coupled code, exposing why that hurts, and refactoring into a clean delegate-based design.

## Pages

Open `DelegateDemo.playground` in Xcode. The pages are numbered in narrative order:

1. **Starter** — the tightly coupled version.
2. **Spaghetti Exposed** — what breaks as this code grows.
3. **Delegate Refactor** — introducing the delegate protocol.
4. **Bulletproof** — hardening the delegate (weak references, optional methods).
5. **Delegates vs The World** — how delegates compare to closures, notifications, and Combine.

## Code along

Open `Starter/DelegateDemo.playground` if you want to type out the refactor yourself.

## Requirements

Xcode 15 or newer.
