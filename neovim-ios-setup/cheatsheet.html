Neovim for iOS — Cheat Sheet

Leader key = Space. Bindings shown in the video setup (xcodebuild.nvim + telescope + LSP). Yours may differ — ask Claude what it wired up.

Build · Run · Test (xcodebuild.nvim)

Space xOpen the Xcode actions menu
Space x bBuild the project
Space x rBuild & run
Space x tRun tests (on the selected simulator)
Space x sSelect / show scheme
Space x dSelect device / destination

First run? Do the one-time project setup (scheme + workspace + device) when prompted.

Find & Navigate (telescope)

Space s sSearch (the telescope entry point)
Space s fFind files (fuzzy)
Space s gLive grep across the project
arrows / EnterMove through results & open

In the video the find/search prefix was remapped from f to s ("s for search").

Lint & Format (LSP / code actions)

Space c fFormat + auto-fix lint on the file
Space c aCode action (apply LSP fix)
:command format disableToggle inline diagnostics off

Essential Vim Movement

h j k lleft / down / up / right
i / Escinsert mode / back to normal
dw · dddelete word · delete line
u · Ctrl+rundo · redo
:w · :qsave · quit
