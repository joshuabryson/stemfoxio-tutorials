# Protocols 5/5 — Associated Types

Code for the **Associated Types** video in the Protocols series on [StemFoxIO](https://www.youtube.com/@StemFoxIO).

Associated types are where protocols get their real power. This playground walks through the compiler error that sends people running from `associatedtype`, then rebuilds intuition by comparing it side by side with generics.

## Pages

Open `AssociatedTypes.playground` in Xcode. The pages are numbered in narrative order:

1. **The Error** — the `associatedtype` error everyone hits first.
2. **Generics in Action** — what the same problem looks like with generics.
3. **Associated Types in Action** — the same shape, restated as an associated type.
4. **Same Concept Revealed** — seeing why these two feel identical.
5. **Combining Them** — using both together where each shines.

## Requirements

Xcode 15 or newer.
